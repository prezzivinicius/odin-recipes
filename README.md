# 🍽️ Minhas Receitas

Projeto simples de site de receitas desenvolvido com **HTML** e **CSS**.

Este projeto foi criado como parte da minha prática em desenvolvimento front-end, com foco em estruturação de páginas, navegação entre arquivos, uso de imagens, listas, classes e estilização com CSS.

---

## 📌 Sobre o projeto

O site apresenta uma página inicial com links para receitas individuais. Cada receita possui imagem, descrição, lista de ingredientes e modo de preparo.

O objetivo principal foi praticar os fundamentos do desenvolvimento web e começar a construir projetos para o meu portfólio.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

---

## 📄 Funcionalidades

- Página inicial com lista de receitas
- Páginas individuais para cada receita
- Links de navegação entre as páginas
- Link para voltar à página inicial
- Imagens das receitas
- Lista de ingredientes com `ul` e `li`
- Modo de preparo com `ol` e `li`
- Estilização com CSS externo
- Uso de classes para organizar o CSS
- Layout responsivo com `@media`

---

## 🧠 O que aprendi

Neste projeto, pratiquei:

- Estrutura básica de um documento HTML
- Uso de tags como `h1`, `h2`, `p`, `ul`, `ol`, `li`, `a`, `img`, `div` e `footer`
- Criação de links internos entre páginas
- Organização de arquivos em pastas
- Caminhos relativos como `../`
- Uso do atributo `alt` em imagens
- Criação e uso de classes no HTML
- Estilização com CSS
- Comentários em HTML e CSS
- Responsividade com `@media`
- Primeiros comandos de Git e GitHub
