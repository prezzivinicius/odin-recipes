# Minhas Receitas

Este é um projeto simples de site de receitas desenvolvido com HTML e CSS.

## Sobre o projeto

O objetivo do projeto é praticar a estrutura básica de páginas HTML, criação de links, uso de imagens, listas, classes e estilização com CSS.

## Tecnologias utilizadas

- HTML
- CSS

## Funcionalidades

- Página inicial com lista de receitas
- Páginas individuais para cada receita
- Links de navegação entre as páginas
- Imagens das receitas
- Listas de ingredientes
- Modo de preparo
- Estilização com CSS
- Layout responsivo para telas menores

## O que aprendi

Neste projeto, pratiquei:

- Estrutura básica do HTML
- Uso de tags como `h1`, `h2`, `p`, `ul`, `ol`, `li`, `a`, `img`, `div` e `footer`
- Uso de classes no HTML
- Estilização com CSS
- Comentários em HTML e CSS
- Caminhos de arquivos com `../`
- Responsividade com `@media`
